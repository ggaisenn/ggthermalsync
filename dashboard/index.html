THE SYSTEM

How it works

Three tiers, the same as a real telemetry stack, in miniature.

TIER 1 · CORE ENGINE

C++17

Integrates every cell's temperature at a fixed 60 Hz step, with a PID loop driving the cooling pump toward a 35 °C setpoint.

01
TIER 2 · TELEMETRY BACKEND

Node.js

Ingests newline-delimited JSON over TCP :9001, keeps a ring buffer of recent frames and broadcasts to browsers over WebSocket.

02
TIER 3 · WEB DASHBOARD

Three.js + Chart.js

Renders the pack as a 3D heatmap with a live HUD, rolling 60 s charts and overheat alerts.

03
